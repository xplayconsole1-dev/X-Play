# X-Play Console — Official Web Platform

The official high-performance web platform for **X-Play Console**, engineering bootable external DirectStorage NVMe console architecture that transforms any everyday laptop or desktop PC into an uncompromised 60 FPS AAA gaming powerhouse with zero latency and zero host drive footprint.

## Features

- **DirectStorage NVMe Speed**: 1,050 MB/s to 3,500 MB/s sustained read speeds.
- **Dedicated Xbox on PC Experience**: 1:1 reverse-engineered PC gaming landing for student editions.
- **Cinematic GSAP & Smooth Scroll**: Pinned video scrubbing, interactive hardware showcase, and live storefront integrations.
- **Storefront Compatibility**: Full support for Steam, Epic Games Store, Xbox Game Pass, and Rockstar Games Launcher.

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
